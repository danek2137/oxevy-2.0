# Oxevy — Minecraft 1.21.4

> ⚠️ **This is not the mainline branch.**
>
> This branch is a frozen snapshot that targets **Minecraft 1.21.4** only. It does
> not receive new features or fixes — current development happens on
> [`main`](https://github.com/danek2137/oxevy-2.0) for **Minecraft 1.21.11**
> (web UIs, MCEF integration and config share codes are 1.21.11-only).

## Requirements

- Java 21
- Minecraft 1.21.4
- Fabric Loader + Fabric API

**MCEF is not required on this branch** — the MCEF/web-UI work lives on mainline.

## Build

```bash
./gradlew build
# jar: build/1.21.4/libs/oxevy-2.5.7.jar
```

Ready-made jars for every supported version are attached to the
[releases](https://github.com/danek2137/oxevy-2.0/releases) page.
